# Mobile App Roadmap

This folder is reserved for the mobile client code.

## Suggested future structure

- `mobile/android/` - Android app code (Kotlin/Jetpack Compose or React Native)
- `mobile/ios/` - iOS app code (SwiftUI or React Native)
- `mobile/shared/` - shared UI/logic components if using cross-platform frameworks

## Next steps

1. Choose a mobile technology stack (React Native, Flutter, Kotlin Multiplatform, or native Swift/Kotlin).
2. Build API integration against `http://localhost:8000/api/health`.
3. Add authentication, task orchestration, and AI prompt routing.
